Prima di iniziare

Bastano pochi minuti e nessuna competenza particolare. Leggete questa pagina una volta: vi evita le sorprese più comuni.

Cosa c'è di nuovo nella 3.1.0

  • Voci italiane maschili e femminili già incluse: le voci naturali Riccardo (uomo) e Paola (donna), più le voci leggere su Linux e tutte le voci italiane di Windows. Si scelgono in Impostazioni → Voce → «Voce del Professore».
  • Quiz e attestati: nove grandi quiz, tra cui il Grande Quiz dell'Informatica (264 domande); con il 70% si ottiene un attestato con il proprio nome, da stampare o salvare in PDF.
  • Cultura generale (26 lezioni), le pagine del libro Tecnologia Gentile e di FeniceOS, una Palestra con 11 esercizi.
  • Quadro dell'aula in rete locale: il PC del facilitatore vede i PC degli allievi e manda messaggi a tutti.
  • Pulsante 🖨️ Stampa, indicatore Online, saluto all'avvio, consigli, promemoria e pulsante 🚪 Esci.
Perché il file è più grandeIl pacchetto per Linux (circa 150 MB) e l'installatore per Windows (circa 107 MB) sono molto più grandi delle versioni 2.x perché contengono le voci naturali, che così funzionano subito e senza Internet. Se la connessione dell'aula è lenta, scaricate il file una volta sola e portatelo sugli altri computer con una chiavetta.

I file si scaricano dal sito del progetto, oppure arrivano su chiavetta dal facilitatore. Dal Professore già installato su Linux si possono anche scaricare da soli (capitolo 2, metodo A).

Controllare che il file sia integro (consigliato)

Se il file è passato da molte chiavette o da una connessione instabile, potrebbe essersi rovinato. L'impronta SHA-256 è un codice che cambia se cambia anche un solo byte del file: deve essere uguale a quella scritta in SHA256SUMS.

LINUX Nella cartella dove avete il file e SHA256SUMS:

sha256sum -c SHA256SUMS --ignore-missing
Deve comparire OK accanto al nome del file. Se compare un errore, scaricate o ricopiate di nuovo il file.

WINDOWS Aprite la cartella del file, scrivete cmd nella barra degli indirizzi in alto e premete Invio; poi:

certutil -hashfile ProfessoreDigitale-Setup-3.1.0.exe SHA256
Confrontate il codice che compare con quello scritto accanto al nome del file in SHA256SUMS (si apre con il Blocco note): devono essere identici.
Prima di aggiornareChiudete il Professore se è aperto. Non è obbligatorio (l'installazione lo chiude da sola), ma evita di interrompere una lezione a metà. Se volete stare doppiamente tranquilli, prima esportate i progressi: Impostazioni → Dati e progressi → ⬇️ Esporta progressi.

Aggiornare su Linux

Avete già il Professore 2.0, 2.1, 2.2, 2.3 o 3.0. La versione 3.1.0 si installa direttamente sopra la precedente: non serve disinstallarla. Scegliete uno dei tre metodi.

Metodo A · Dal Professore (il più semplice)

  1. Collegate il computer a Internet e aprite il Professore Digitale.
  2. Andate in ⚙️ Impostazioni, scheda 🔄 Aggiornamenti.
  3. Premete 🌐 Controlla aggiornamenti: compare «È disponibile la versione 3.1.0» con l'elenco delle novità.
  4. Premete ⬇️ Scarica il nuovo pacchetto. Il file viene salvato nella cartella Scaricati e verificato da solo con la sua impronta.
  5. Il Professore mostra il comando da scrivere: copiatelo e proseguite con il metodo B dal passo 2.

Metodo B · Dal terminale (il più affidabile)

  1. Aprite la cartella Scaricati (o quella dove si trova il file), fate clic destro in uno spazio vuoto e scegliete Apri nel terminale (su alcuni sistemi: Apri un terminale qui).
  2. Scrivete il comando e premete Invio: 
    sudo apt install ./professore-digitale_3.1.0_all.deb
  3. Scrivete la password del computer e premete Invio. Mentre la scrivete non compare nulla, nemmeno gli asterischi: è normale.
  4. Se compare una domanda «Continuare? [S/n]», premete S e Invio. Aspettate il ritorno del cursore.
  5. Controllate la versione: 
    professore-digitale --version
    Risposta attesa: Professore Digitale 3.1.0
Il «./» è indispensabileIl punto e la barra davanti al nome dicono ad apt di usare il file della cartella, invece di cercarlo su Internet. Senza, compare «Impossibile trovare il pacchetto».

Metodo C · Con il doppio clic

Fate doppio clic su professore-digitale_3.1.0_all.deb: si apre l'installatore del sistema (Software Center, GDebi, Discover o simili). Premete Aggiorna o Installa e inserite la password. Sui computer più lenti questi programmi possono sembrare bloccati: aspettate, oppure usate il metodo B.

Se il vostro centro usa il «repository»

Se il facilitatore ha configurato il Professore come fonte di aggiornamenti del sistema, la 3.1.0 arriva con gli altri aggiornamenti (Gestore aggiornamenti), oppure dal terminale:

sudo apt update
sudo apt install --only-upgrade professore-digitale

Dopo l'aggiornamento

Se il Professore era aperto, chiudetelo e riapritelo dal menu delle applicazioni (categoria Istruzione): il Professore vi saluta con la sua nuova voce. I componenti facoltativi già installati (IA con Ollama, microfono) continuano a funzionare senza rifare nulla; la voce si sceglie in Impostazioni → Voce. Progressi, impostazioni e conversazioni restano: le novità (quiz, cultura, aula) si aggiungono. Per scegliere un modello di IA più recente: capitolo 3, «Componenti facoltativi».

Prima installazione su Linux

Il pacchetto funziona sulle distribuzioni basate su Debian con Python 3.7 o successivo: Debian 10–13, Ubuntu dalla 20.04, Linux Mint, Q4OS, Zorin OS, MX Linux, antiX, FeniceOS e derivate. L'installazione non scarica nulla da Internet, salvo la voce italiana di sistema se manca.

  1. Copiate professore-digitale_3.1.0_all.deb nella cartella Scaricati. Non installatelo direttamente dalla chiavetta.
  2. Aprite il terminale in quella cartella (clic destro → Apri nel terminale) e scrivete: 
    sudo apt install ./professore-digitale_3.1.0_all.deb
  3. Inserite la password (non si vede mentre la scrivete) e confermate con S se richiesto. Il pacchetto contiene già le voci naturali Riccardo e Paola; il sistema installa anche, se mancano, la voce leggera espeak-ng e i caratteri con le icone colorate.
  4. Controllate: 
    professore-digitale --version          # Professore Digitale 3.1.0
professore-digitale --status           # mostra IA, voci e microfono disponibili
  5. Aprite il Professore dal menu delle applicazioni, categoria Istruzione, oppure scrivendo professore-digitale.

Componenti facoltativi (serve Internet una sola volta)

professore-digitale-setup-iaInstalla Ollama e propone il modello di IA adatto alla memoria del computer (da Qwen 3.5 · 0,8 miliardi per 4 GB fino a Gemma 4 · 12 miliardi per 24 GB e oltre). Chiede la password.
professore-digitale-setup-ia --modello qwen3.5:4bInstalla direttamente un modello preciso.
professore-digitale-setup-voceAttiva il microfono offline (modello italiano Vosk, circa 50 MB), senza password.

Le stesse procedure si trovano nel menu delle applicazioni: Professore Digitale: configura IA e configura microfono. Dopo l'installazione di un componente, nel Professore andate in Impostazioni → 🔄 Ricontrolla i componenti (oppure riavviatelo).

Avete già un modello di IA?Non è obbligatorio cambiarlo: il Professore continua a usare quello installato. Per provare un modello più recente, eseguite professore-digitale-setup-ia e poi sceglietelo in Impostazioni → Intelligenza artificiale → Modello. Il vecchio si toglie con ollama rm NOME (per vedere i nomi: ollama list).

Installare su Windows

Un solo installatore va bene per tutti i computer, da Windows XP a Windows 11. L'installazione non scarica nulla da Internet e richiede un paio di minuti. Se avete già la 2.3, eseguitelo sopra: non serve disinstallare.

  1. Copiate ProfessoreDigitale-Setup-3.1.0.exe sul desktop o nella cartella Download e fate doppio clic.
  2. Se compare la finestra blu «Windows ha protetto il PC», fate clic su Ulteriori informazioni e poi su Esegui comunque. Accade con tutti i programmi nuovi senza firma digitale a pagamento; il Professore è software libero e verificabile con la sua impronta.
  3. Se Windows chiede «Consentire a questa app di apportare modifiche?», rispondete Sì.
  4. Pagina di benvenuto e licenza: premete Avanti.
  5. Scegliete per chi installare:
    • Per tutti gli utenti del computer (consigliato nelle aule, serve la password di amministratore; aggiunge la regola del firewall per il quadro dell'aula);
    • Solo per me (non chiede password, va bene a casa).
  6. Lasciate le spunte proposte: programma, icona sul desktop e — sui Windows a 64 bit — il motore del microfono e le voci naturali Paola e Riccardo. Premete Avanti, poi Installa.
  7. Nell'ultima pagina lasciate la spunta «Configura subito IA e voce» se il computer è collegato a Internet, oppure solo «Apri il Professore Digitale». Premete Fine.

Configurare IA e voce

Si apre dal menu a sinistra 🧰 Configura IA e voce, dal menu Start → Professore Digitale → Configura IA e voce, o con il tasto destro sull'icona del Professore vicino all'orologio. Il programma esamina il computer, propone il modello di IA adatto e installa tutto con ▶ Configura automaticamente: Ollama su Windows 10 22H2 e 11, il motore compatibile su Windows 7, 8 e 8.1 a 64 bit. Le voci naturali sono già incluse sui Windows a 64 bit (da Windows 7). Su Windows XP, Vista e sui sistemi a 32 bit il Professore usa la sua guida interna. I dettagli sono nel Vademecum per Windows, capitolo 14.

Windows XP e Vista

Serve un browser moderno: Supermium. Installatelo prima del Professore dalla chiavetta preparata dal facilitatore (cartella ProfessoreDigitale-kit\browser). Se il Professore si apre in Internet Explorer, compare un messaggio con le istruzioni.

Controllare la versione

Tasto destro sull'icona del Professore vicino all'orologio → Apri il Professore Digitale → Impostazioni → Informazioni: deve dire 3.1.0. Oppure WINDOWS nel Prompt dei comandi:

"%LOCALAPPDATA%\Programs\ProfessoreDigitale\ProfessoreDigitale.exe" --version
rem se installato per tutti gli utenti:
"%ProgramFiles(x86)%\ProfessoreDigitale\ProfessoreDigitale.exe" --version

Sui Windows a 32 bit la seconda cartella è %ProgramFiles%\ProfessoreDigitale.

Aggiornare su Windows

Dalla 2.3 alla 3.1.0, e poi alle versioni successive: due strade, entrambe senza disinstallare e senza perdere nulla.

Dal Professore

  1. Con il computer collegato a Internet: ⚙️ Impostazioni → 🔄 Aggiornamenti → 🌐 Controlla aggiornamenti.
  2. Se c'è una versione nuova, leggete le novità e premete ⬇️ Scarica il nuovo pacchetto: il file va nella cartella Download e viene verificato con la sua impronta. Per la 3.1.0 sono circa 107 MB: con una connessione lenta ci vuole qualche minuto.
  3. Premete ▶ Installa adesso: il Professore si chiude e parte l'installatore. Seguite le pagine come nel capitolo 4 e riapritelo alla fine.
Dalla 2.3 alla 3.0: cosa resta e cosa cambiaRestano progressi delle lezioni, record della Palestra, impostazioni, conversazione, contenuti aggiunti, IA e microfono configurati. Si aggiungono quiz e attestati, cultura generale, aula, saluti e promemoria. Se avevate scaricato la voce «Paola» dalla 2.3, ora la trovate già inclusa insieme a «Riccardo»: sceglietela in Impostazioni → Voce.

Con il file

Fate doppio clic sul nuovo ProfessoreDigitale-Setup-X.Y.Z.exe (dal sito o dalla chiavetta) e seguite le stesse pagine del capitolo 4. L'installatore chiude da solo il Professore aperto, sostituisce i file del programma e lascia intatti i dati.

Ripara ancheRieseguire l'installatore della stessa versione è il modo più semplice per «riparare» un Professore che si comporta in modo strano dopo un'interruzione di corrente: i file del programma vengono riscritti, i dati restano.

Solo nuovi contenuti o nuovi modelli di IA

Domande, lezioni e l'elenco dei modelli di IA consigliati si aggiornano senza installare nulla: dopo Controlla aggiornamenti premete ➕ Aggiungi o 🔄 Aggiorna accanto ai contenuti; in Configura IA e voce premete Cerca un catalogo più recente.

Molti computer e chiavetta

Per le aule, i centri anziani e le scuole: come aggiornare molti computer in poco tempo, anche dove Internet non c'è.

LINUX Con la chiavetta di aggiornamento

Il facilitatore prepara una chiavetta con la cartella professore-digitale (contiene il pacchetto, i contenuti e lo script). Su ogni PC:

# aprite il terminale nella cartella della chiavetta, poi:
sh installa-da-chiavetta.sh

Lo script controlla le impronte, installa o aggiorna solo se serve e conserva i progressi.

LINUX Con un PC dell'aula che fa da server

Se il facilitatore ha attivato un «server degli aggiornamenti» nella rete dell'aula, su ogni PC basta: Impostazioni → Aggiornamenti, scrivere l'indirizzo indicato (per esempio http://192.168.1.10:8080/aggiornamenti.json) e premere Controlla aggiornamenti, poi seguire il capitolo 2.

WINDOWS Installazione silenziosa

Da un Prompt dei comandi aperto come amministratore, nella cartella dell'installatore (anche dalla chiavetta):

rem per tutti gli utenti del computer, senza domande
ProfessoreDigitale-Setup-3.1.0.exe /S /AllUsers
rem solo per l'utente attuale, senza password
ProfessoreDigitale-Setup-3.1.0.exe /S /CurrentUser

Si può mettere la riga in un file installa.bat sulla chiavetta e lanciarlo con doppio clic su ogni PC.

WINDOWS IA e voce senza Internet

  1. Su un PC collegato: Configura IA e voce → Computer senza Internet, scegliete il tipo di Windows dei PC di destinazione e il modello, poi 💾 Prepara la chiavetta. Si crea la cartella ProfessoreDigitale-kit, con ogni file e la sua impronta.
  2. Su ogni PC senza rete: installate il Professore, aprite Configura IA e voce e premete 📥 Installa dalla chiavetta, scegliendo la cartella ProfessoreDigitale-kit. Un file rovinato viene rifiutato con una spiegazione.
Più allievi sullo stesso computerI progressi appartengono all'utente del computer: con un account per allievo ognuno ritrova il proprio percorso. Su Windows installate «per tutti gli utenti».

AULE Il quadro dell'aula e il firewall

Con il menu 🏫 Aula un PC diventa quello del facilitatore e gli altri quelli degli allievi: il facilitatore vede chi è collegato, cosa sta facendo, lezioni, quiz e attestati, e può mandare un messaggio a tutti. Funziona nella rete locale (stesso Wi-Fi o cavo), senza Internet. Il PC del facilitatore riceve i collegamenti sulle porte 8766 TCP e 8767 UDP; i PC degli allievi non hanno bisogno di nulla.

WINDOWS Installando «per tutti gli utenti» (anche con /S /AllUsers) l'installatore aggiunge da solo la regola del firewall «Professore Digitale (aula)» per le reti private, e la toglie quando disinstallate. Con l'installazione «solo per me», la prima volta che scegliete «Il PC del facilitatore» Windows può chiedere se consentire l'accesso: scegliete le reti private e Consenti accesso.

LINUX Su molte distribuzioni il firewall è spento e non serve nulla. Se sul PC del facilitatore è attivo ufw (sudo ufw status):

sudo ufw allow 8766/tcp
sudo ufw allow 8767/udp

Poi, nel Professore: 🏫 Aula → «Il PC del facilitatore», un codice dell'aula, 💾 Salva e applica; nel riquadro «Questo PC» deve comparire In ascolto per gli allievi ✅. Sui PC degli allievi: 🏫 Aula → «Il PC di un allievo», nome e codice, 💾 Salva e applica.

Versione portatile e da chiavetta

Per una prova veloce, o sui computer che non si possono modificare (biblioteca, ufficio).

Versione portatile · TUTTI

Fate doppio clic su professore-digitale-portatile.html: si apre nel browser e funziona subito, anche da chiavetta e su qualsiasi sistema. Ci sono lezioni, quiz con attestato, cultura generale, guida interna, lavagna, palestra e voce del browser; mancano IA, voci naturali, microfono e quadro dell'aula. I progressi restano nella memoria del browser di quel computer: per aggiornare basta sostituire il file con quello nuovo, i progressi restano.

Versione da chiavetta per Windows · WINDOWS

  1. Clic destro su professore-digitale-windows-3.1.0.zip → Estrai tutto, scegliendo la chiavetta.
  2. Aprite la cartella ProfessoreDigitale e fate doppio clic su ProfessoreDigitale.exe.
  3. I progressi vengono salvati nella sottocartella dati accanto al programma: la chiavetta passa da un PC all'altro con il proprio percorso.

Per aggiornare la versione da chiavetta: estraete il nuovo zip in una cartella nuova e poi copiate dentro la vecchia sottocartella dati.

CAPITOLO

Se un giorno volete togliere tutto

Per aggiornare non serve mai disinstallare. Queste istruzioni servono solo per restituire il computer «come nuovo», per esempio prima di donarlo.

LINUX

# 1. da ogni utente che ha usato il Professore: cancella i suoi dati e progressi
professore-digitale-pulizia
# 2. toglie il programma e le sue icone
sudo apt purge professore-digitale
sudo apt autoremove --purge
# 3. facoltativo: i modelli di IA (vedere i nomi, poi toglierli)
ollama list
ollama rm NOME-DEL-MODELLO

Se avevate aperto le porte dell'aula: sudo ufw delete allow 8766/tcp e sudo ufw delete allow 8767/udp.

WINDOWS

  1. Start → Impostazioni → App (o Pannello di controllo → Programmi e funzionalità) → Professore Digitale → Disinstalla.
  2. Alla domanda «Volete cancellare anche i progressi…» rispondete Sì per una pulizia completa, No se pensate di reinstallare. Vengono tolte anche le voci incluse e la regola del firewall per l'aula.
  3. Facoltativo: Ollama si toglie dallo stesso elenco di app.
